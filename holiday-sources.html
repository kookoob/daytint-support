Updates and limitations

Reviewed data is bundled in the app for offline use. Refresh downloads the same public file from Daytint on GitHub Pages. New years and one-off holidays are added after official verification. Local holidays, workplace-specific entitlements and Chinese working weekends are not included. This calendar does not claim government endorsement.

Previously downloaded Nager API data is not imported by version 1.0. Earlier 0.4 TestFlight versions may still use that provider.
